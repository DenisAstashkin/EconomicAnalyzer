## 📋 Системные требования

Для успешного запуска и работы проекта на вашем компьютере должны быть установлены следующие инструменты:

### 1. Программное обеспечение
* **Python 3.11.x** (Рекомендуется версия `3.11.9`) — [Скачать Python](https://python.org)
* **Docker Desktop** (Или Docker Engine для Linux) — [Скачать Docker](https://docker.com)
* **Git** — для клонирования репозитория — [Скачать Git](https://git-scm.com)

### 2. Спецификация железа (Hardware)
* **Процессор (CPU):** С поддержкой инструкций **AVX2** (необходимо для стабильной работы библиотеки TensorFlow на процессоре).
* **Оперативная память (RAM):** Минимум **4 ГБ** (рекомендуется от 8 ГБ, так как TensorFlow и Redis требуют свободных ресурсов).
* **Видеокарта (GPU):** *Опционально*. По умолчанию проект настроен на работу на CPU. Для работы на видеокарте требуются установленные драйверы NVIDIA CUDA.

### 3. Ключевые зависимости (Python)
Основные библиотеки, которые будут автоматически установлены из файла `requarement.txt`:
* **FastAPI** + **Uvicorn** — веб-фреймворк и асинхронный сервер.
* **TensorFlow** — для работы алгоритмов анализа данных.
* **Redis** — клиент для интеграции с базой данных.

# 🛠️ Шаг 1. Запуск Redis в Docker
Вам не нужно создавать сложные файлы конфигурации, достаточно поднять официальный контейнер Redis одной командой в терминале.

```bash
docker pull redis:trixie
docker run --name economic-redis -p 6379:6379 -d redis:trixie
```

*    `--name economic-redis` — понятное имя для контейнера базы данных.
*    `-p 6379:6379` — проброс порта 6379 из контейнера на ваш локальный компьютер (localhost).
*    `-d` — запуск в фоновом режиме.

# 💻 Шаг 2. Настройка и запуск FastAPI локально
Так как приложение будет работать прямо на вашем компьютере, оно сможет подключиться к Redis через стандартный адрес localhost:6379.
### Шаг 2.1. Клонирование и переход в папку
Откройте ваш терминал и выполните команды:
```bash
git clone https://github.com/DenisAstashkin/EconomicAnalyzer/
cd EconomicAnalyzer
```

### Шаг 2.2. Создание виртуального окружения
Изолируйте зависимости проекта от глобальной системы:

* **Для Windows (cmd/PowerShell):**
  ```bash
  py -3.11 -m venv .venv
  .venv\Scripts\activate.bat
  ```
* **Для macOS / Linux:**
  ```bash
  python3 -3.11 -m venv .venv
  source .venv/bin/activate
  ```

### Шаг 2.3. Установка библиотек
Обновите пакетный менеджер и установите все необходимые зависимости:
```bash
pip install --upgrade pip
pip install -r requarement.txt
```

### Шаг 2.4. Запуск сервера разработки
Запустите Uvicorn с флагом автоперезапуска при изменении кода (`--reload`):
```bash
python -m uvicorn src.server:app --reload
```

Приложение успешно запущено и доступно по адресу: **[http://127.0.0.1:8000](http://127.0.0.1:8000)**
