# 📉 EconomicAnalyzer

## 📋 Системные требования

Для успешного запуска и работы проекта на вашем компьютере должны быть установлены следующие инструменты:

### 1. Программное обеспечение
* **Python 3.11.x** (Рекомендуется версия `3.11.9`) — [Скачать Python](https://python.org)
* **Docker** (Docker Desktop для Windows/macOS или Docker Engine для Linux) — [Скачать Docker](https://docker.com)
* **Git** — для клонирования репозитория — [Скачать Git](https://git-scm.com)

> 💡 **Быстрая установка для Windows:** Откройте PowerShell от имени администратора и выполните:  
> `winget install Python.Python.3.11 Docker.DockerDesktop Git.Git` *(после установки перезапустите терминал)*.

### 2. Спецификация железа (Hardware)
* **Процессор (CPU):** С поддержкой инструкций **AVX2** (необходимо для стабильной работы библиотеки TensorFlow на процессоре).
* **Оперативная память (RAM):** Минимум **4 ГБ** (рекомендуется от 8 ГБ, так как TensorFlow и Redis требуют свободных ресурсов).
* **Видеокарта (GPU):** *Опционально*. По умолчанию проект настроен на работу на CPU. Для работы на видеокарте требуются установленные драйверы NVIDIA CUDA.

### 3. Ключевые зависимости (Python)
Основные библиотеки, которые будут автоматически установлены из файла `requarement.txt`:
* **FastAPI** + **Uvicorn** — веб-фреймворк и асинхронный сервер.
* **TensorFlow** — для работы алгоритмов анализа данных.
* **Redis** — клиент для интеграции с базой данных.

## 🛠️ Шаг 1. Запуск Redis в Docker

Перед запуском команды на Windows или macOS обязательно убедитесь, что приложение **Docker Desktop** открыто и работает.

Выполните команду в терминале для скачивания и запуска официального контейнера базы данных:

```bash
docker pull redis:latest
docker run --name economic-redis -p 6379:6379 -d redis:latest
```

* `--name economic-redis` — понятное имя для контейнера базы данных.
* `-p 6379:6379` — проброс порта 6379 из контейнера на ваш локальный компьютер (`localhost`).
* `-d` — запуск контейнера в фоновом режиме.

## 💻 Шаг 2. Настройка и запуск FastAPI локально

Приложение будет работать прямо на вашем компьютере и автоматически подключится к запущенному в Docker контейнеру Redis через стандартный адрес `localhost:6379`.

### Шаг 2.1. Клонирование и переход в папку
Откройте ваш терминал (Bash, CMD или PowerShell) и выполните команды:
```bash
git clone https://github.com.git
cd EconomicAnalyzer
```

### Шаг 2.2. Создание и активация виртуального окружения
Изолируйте зависимости проекта от глобальной системы, выбрав блок команд под вашу ОС:


* **Для Windows (cmd/PowerShell):**
  ```bash
  python.exe -m venv .venv
  .venv\Scripts\activate

  ```
* **Для Windows (PowerShell):**
  ```powershell
  py -3.11 -m venv .venv
  .venv\Scripts\Activate.ps1
  ```
  *Если возникает ошибка безопасности выполнения скриптов, предварительно введите:*  
  `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process`
* **Для macOS / Linux:**
  ```bash
  python3.11 -m venv .venv
  source .venv/bin/activate
  ```

### Шаг 2.3. Установка библиотек
Убедитесь, что в начале строки терминала появилось обозначение окружения `(.venv)`. Обновите пакетный менеджер и установите все необходимые зависимости:
```bash
python -m pip install --upgrade pip
pip install -r requarement.txt
```

> ⚠️ **Примечание для Windows:** Если ваш процессор старый и не поддерживает инструкции AVX2, библиотека `tensorflow` может вызвать ошибку при запуске. В таком случае замените строку `tensorflow` в файле `requarement.txt` на `tensorflow-cpu`.

### Шаг 2.4. Запуск сервера разработки
Запустите Uvicorn с флагом автоматического перезапуска при изменении кода (`--reload`):
```bash
python -m uvicorn src.server:app --reload
```

Приложение успешно запущено и доступно по адресу: **[http://127.0.0.1:8000](http://127.0.0.1:8000)**
